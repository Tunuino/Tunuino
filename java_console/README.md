# Consola Java (legado)

Esta implementação JavaFX permanece no repositório porque os workflows atuais de Windows Console, Desktop e Bundle ainda a compilam e utilizam nos artefactos. **Não é a nova interface Qt 6 da Tunuino Console.**

Compilação de desenvolvimento: `./gradlew :java_console:assemble`.

Não remover este módulo sem atualizar primeiro os workflows, o empacotamento, os testes e as referências ao executável.
